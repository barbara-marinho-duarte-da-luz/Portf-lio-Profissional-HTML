# 💻 Portfólio Profissional | Barbara Marinho Duarte da Luz

> Portfólio acadêmico e profissional desenvolvido para apresentar minha trajetória, projetos práticos e evolução técnica no desenvolvimento de software e front-end.

---

## 📌 Sobre o Projeto

Este projeto é uma **landing page responsiva** desenvolvida com foco em organização visual, legibilidade e boas práticas de interface. A página funciona como um ponto central para exibição do meu perfil profissional, tecnologias dominadas, projetos desenvolvidos e canais de contato.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas e bibliotecas:

* **HTML5:** Estruturação semântica de conteúdo.
* **CSS3:** Estilização personalizada e ajustes de responsividade (mídia e carrossel).
* **Bootstrap 5.3:** Framework para grid system, componentes responsivos (Navbar, Carrossel, Cards) e utilitários.
* **Devicon:** Ícones vetoriais das linguagens e ferramentas.

---

## 🧩 Funcionalidades e Estrutura

- **Navbar Fixa e Responsiva (`sticky-top`):** Menu superior com alternância em dispositivos móveis e navegação por âncoras (`#perfil`, `#projetos`, `#contato`).
- **Carrossel de Destaques:** Apresentação visual dinâmica utilizando efeito fade do Bootstrap.
- **Seção de Perfil:** Apresentação pessoal, objetivos de carreira, localização e cards com as principais tecnologias (HTML5, CSS3, Bootstrap, Python, GitHub e VS Code).
- **Galeria de Projetos:** Cards responsivos com links diretos para os repositórios:
  - *Sistema em HTML:* Portal de entretenimento digital.
  - *Monitoramento de Reservatório de Água:* Aplicação desenvolvida em Python para análise de dados e consumo de reservatório municipal.
  - *Landing Page Responsiva:* Demonstração de interfaces focadas em experiência do usuário.
- **Seção de Contato & Apresentação:** Incorporação de vídeo/mídia interativa e cartões com atalhos para E-mail, GitHub e LinkedIn.
